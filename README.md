# 概念跃迁器 · 费曼式深度理解训练站

> 把「我以为我懂了」逼成「我真的能讲清楚」：四道环节，**单次 ≤ 8 分钟**，每次反馈恒为 3 条且必含一条可执行动作。

## 1. 这是什么

基于费曼学习法的**概念理解训练器**。针对的是最常见也最难自查的状态：一个概念你「认识」「能复述定义」，但换一种问法就露馅。

| # | 环节 | 逼出的是什么 |
|---|---|---|
| 01 | 用自己的话说 | 你是不是在用行话冒充理解 |
| 02 | 教材之外的例子 | 你能不能脱离课本原型迁移 |
| 03 | 三个场景判断 | 你能不能识别边界条件 |
| 04 | 设计陷阱题 | 你能不能预判别人会怎么误解 |
| 05 | 理解跃迁档案 | 12 周可回溯，生成重练提醒 |

### 当前版本的性质

- 单文件纯前端，双击 `index.html` 即可运行，**不含任何外部网络请求**；
- 训练记录与档案保存在浏览器 **localStorage** 中；
- 页面内含**完整的 AI 提示词原文**（见下文），可直接复制到任意大模型使用；原型本身不调用模型服务，评分与反馈以规则逻辑演示。

## 4. 训练环节详解

### 01 用自己的话说（去术语复述）

- **规则**：作答前**不给定义**；用 ≤ 80 字讲给门外汉；命中行话仅柔化描边提示。
- **评分维度**：去术语率 / 机制完整度 / 可迁移性（各 0–3 分）。
- **反馈模板**：「你说：『…』仍是行话」→「断在『…』」→「改写成『因为…所以…』」。
- **记录字段**：原句片段 / 回显数 / 三项分 / 改进动作。

<details><summary>AI 提示词原文</summary>

```text
你是认知诊断教练，概念={{concept}}。铁律：作答前禁给定义。请用户≤80字讲给门外汉。收到后：①标回显行话；②按【去术语率/机制完整度/可迁移性】各0–3分；③只给3条反馈：第1条「你说：」引原句≤12字，第2条指缺口，第3条须为30秒可做的动作。禁用「你错了」。
```

</details>

### 02 教材之外的例子

- **规则**：举一个教材外、亲历或**可核查**的例子，并标出「哪一步体现了该概念」；若是课本原型或泛指，只追问「当时发生在哪」，**不给范例**。
- **评分维度**：可核查性 / 属性对齐 / 教材距离（各 0–3 分）。
- **界面**：例子框 + 来源标签 + 「哪一步生效」框。

<details><summary>AI 提示词原文</summary>

```text
概念={{concept}}。禁复述上一版答案。举一个教材外、亲历或可核查的例子，并标出「哪一步体现了{{concept}}」；若是课本原型或泛指，只追问「当时发生在哪」，不给范例。评分【可核查性/属性对齐/教材距离】各0–3分；反馈3条：第1条引原句≤12字，第3条为可行动作。
```

</details>

### 03 三个场景判断（迭代版）★

- **规则**：3 个候选场景 —— ①明显适用；②条件依赖的边界；③看似适用实则不適用。**判断前不作标注**。用户对每个判「适用 / 不适用 / 看情况」并写一句依据。
- **评分维度**：判断一致性 / 前提识别 / 依据说服力（各 0–3 分）。
- **反馈模板**：「你说：『因为…』抓到了」→「换成 X 会翻面吗」→「补一句边界前提」。

<details><summary>AI 提示词原文</summary>

```text
概念={{concept}}。生成3个候选场景：①明显适用；②条件依赖的边界；③看似适用实则不適用，判断前不作标注。请用户对每个判「适用/不适用/看情况」并写一句依据。按【判断一致性/前提识别/依据说服力】各0–3分，给3条反馈：第1条引其依据原句，第2条提问补前提，第3条为可行动作。
```

</details>

### 04 设计陷阱题（反向出题）

- **规则**：**角色反转** —— 请你设计一道把该概念讲错的题（题干 + ≥2 选项），指出最像对的错解错在哪与如何补救；不代出题干，只诊断。
- **评分维度**：隐蔽度 / 错位定位 / 纠正解释力（各 0–3 分）。
- **反馈模板**：「你说：『选项B…』贴近误解」→「这个错法太易排除」→「让干扰项也成立一半」。

<details><summary>AI 提示词原文</summary>

```text
概念={{concept}}。角色反转：请用户设计一道把该概念讲错的题（题干＋≥2选项），指出最像对的错解错在哪与如何补救；不代出题干，只诊断。评分【隐蔽度/错位定位/纠正解释力】各0–3分；反馈3条：第1条引其题中原句≤12字，第2条看是否命中误解，第3条为可行动作。
```

</details>

### 05 理解跃迁档案

- **能力**：读取近 12 周记录，输出①一条**误解诊断**（描述反复出现的模式，不作否定判断）；②四维度跃迁趋势（**只与本人历史比**）；③按 1/3/7/21 天生成重练提醒与提问角度。
- **界面**：只读视图 —— 诊断条 + 四维度趋势 + 四周热力。
- **记录字段**：日期 / 概念 / 四环节分 / 误解标签 / 是否完成。

<details><summary>AI 提示词原文</summary>

```text
读取用户近12周跃迁记录（四环节得分、回显数、漏掉前提、误解标签、动作完成态）。输出：①一条误解诊断，描述反复出现的模式，不作否定判断；②四维度跃迁趋势，只与其本人历史比；③按1/3/7/21天生成重练提醒与提问角度。禁出现排行榜、他人数据与「掌握度百分比」式结论。
```

</details>

| 单环节反馈 | 恒为 3 条，必含 1 条可执行改进动作 |

| 界面原则 | 一次只呈现一个任务 |

---

## 6. 硬约束（设计红线）

1. **禁止先给标准答案再让用户复述** —— 教材说法只能在用户作答后以「另一种说法」对照出现；
2. **禁止「你错了 / 理解有误」式否定反馈** —— 统一改为「换个说法会更稳」；
3. **每条反馈必须引用用户原话 ≤ 12 字并指出位置**；
4. **不出现分数排行榜与他人排名**；
5. **连续训练满 30 分钟必须出现休息提示**。

## 8. 已知限制

- 原型不含模型调用，评分与反馈以规则逻辑演示，提示词原文可直接复制到外部大模型使用；
- 无账号体系，档案仅存于本地浏览器；
- 场景判断与陷阱题由用户输入驱动，原型不自动生成题目文本。
