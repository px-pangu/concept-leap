# 概念跃迁器 · 费曼式深度理解训练站 — 训练流程清单

**全局基线**：单次训练 ≤ 8 分钟、4 个任务；每环节反馈 ≤ 3 条且必含 1 条可执行改进动作；理解跃迁档案可回溯 12 周；界面一次只呈现一个任务。
**硬约束**：① 禁止先给标准答案再让用户复述，教材说法只能在用户作答后以「另一种说法」对照出现；② 禁止「你错了 / 理解有误」式否定反馈，统一改为「换个说法会更稳」；③ 每条反馈必须引用用户原话 ≤ 12 字并指出位置；④ 不出现分数排行榜与他人排名；⑤ 连续训练满 30 分钟必须出现休息提示。
**迭代说明**：第 ③ 环节由「画出与相邻概念的边界」调整为「给出 3 个候选场景，请用户逐一判断该概念是否适用，并为每个判断写一句依据」，其余三个环节与档案模块保持不变。
**视觉基调**：浅灰白底 `#F4F4F1` + 单一强调色墨靛 `#24506C`（只用其透明度梯度作层次），大留白、细描边、去中心化布局。

### 01 用自己的话说

- **环节**：去术语复述：不讲那个词
- **AI 提示词原文**：
```text
你是认知诊断教练，概念={{concept}}。铁律：作答前禁给定义。请用户≤80字讲给门外汉。收到后：①标回显行话；②按【去术语率/机制完整度/可迁移性】各0–3分；③只给3条反馈：第1条「你说：」引原句≤12字，第2条指缺口，第3条须为30秒可做的动作。禁用「你错了」。
```
- **用户作答区设计**：≤80字输入框＋实时计数；命中行话仅柔化描边
- **评分维度**：去术语率 / 机制完整度 / 可迁移性
- **反馈模板**：「你说：『…』仍是行话」→「断在『…』」→「改写成『因为…所以…』」
- **跃迁记录字段**：原句片段 / 回显数 / 三项分 / 改进动作

### 02 教材之外的例子

- **环节**：换例子：教材外的亲身经历
- **AI 提示词原文**：
```text
概念={{concept}}。禁复述上一版答案。举一个教材外、亲历或可核查的例子，并标出「哪一步体现了{{concept}}」；若是课本原型或泛指，只追问「当时发生在哪」，不给范例。评分【可核查性/属性对齐/教材距离】各0–3分；反馈3条：第1条引原句≤12字，第3条为可行动作。
```
- **用户作答区设计**：例子框＋来源标签＋「哪一步生效」框
- **评分维度**：可核查性 / 属性对齐 / 教材距离
- **反馈模板**：「你说：『上次…』站得住」→「对齐的是次要属性」→「补一句当时情形」
- **跃迁记录字段**：例子摘要 / 来源标签 / 对齐点 / 三项分

### 03 三个场景判断（迭代版）

- **环节**：三场景判断＋依据
- **AI 提示词原文**：
```text
概念={{concept}}。生成3个候选场景：①明显适用；②条件依赖的边界；③看似适用实则不適用，判断前不作标注。请用户对每个判「适用/不适用/看情况」并写一句依据。按【判断一致性/前提识别/依据说服力】各0–3分，给3条反馈：第1条引其依据原句，第2条提问补前提，第3条为可行动作。
```
- **用户作答区设计**：3张场景卡，每张三选一＋依据框
- **评分维度**：判断一致性 / 前提识别 / 依据说服力
- **反馈模板**：「你说：『因为…』抓到了」→「换成X会翻面吗」→「补一句边界前提」
- **跃迁记录字段**：三个判断 / 依据原句 / 漏掉前提 / 三项分

### 04 设计陷阱题

- **环节**：反向出题：亲手讲错一次
- **AI 提示词原文**：
```text
概念={{concept}}。角色反转：请用户设计一道把该概念讲错的题（题干＋≥2选项），指出最像对的错解错在哪与如何补救；不代出题干，只诊断。评分【隐蔽度/错位定位/纠正解释力】各0–3分；反馈3条：第1条引其题中原句≤12字，第2条看是否命中误解，第3条为可行动作。
```
- **用户作答区设计**：题干框＋选项行（可增删）＋错在哪＋怎么补救
- **评分维度**：隐蔽度 / 错位定位 / 纠正解释力
- **反馈模板**：「你说：『选项B…』贴近误解」→「这个错法太易排除」→「让干扰项也成立一半」
- **跃迁记录字段**：陷阱题干 / 错位靶点 / 误解标签 / 改进动作

### 05 理解跃迁档案

- **环节**：沉淀 12 周可回溯档案
- **AI 提示词原文**：
```text
读取用户近12周跃迁记录（四环节得分、回显数、漏掉前提、误解标签、动作完成态）。输出：①一条误解诊断，描述反复出现的模式，不作否定判断；②四维度跃迁趋势，只与其本人历史比；③按1/3/7/21天生成重练提醒与提问角度。禁出现排行榜、他人数据与「掌握度百分比」式结论。
```
- **用户作答区设计**：只读视图：诊断条＋四维度趋势＋四周热力
- **评分维度**：趋势可读性 / 误区收敛度 / 重练履约率
- **反馈模板**：「你三次停在同一处」→「这次提前补了前提」→「下周只复练①③」
- **跃迁记录字段**：日期 / 概念 / 四环节分 / 误解标签 / 是否完成

## 附：字数与口径自检

- **字数口径**：统计每个模块六个字段的正文字符数（不含序号、`-` 列表符、字段名与代码块围栏），5 个模块均在 240 字以内。
- **单次上限**：每模块反馈恒为 3 条，第 1 条必含用户原话引用，第 3 条必含一个 30 秒至 2 分钟内可完成的动作。
- **不出现的内容**：任何前置的标准答案；任何「你错了 / 理解有误 / 掌握度不足」句式；任何与他人比较的总分或名次；任何连续训练满 30 分钟而无提示的情形。
